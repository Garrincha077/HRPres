# HRPres — hrvatske sudske odluke

Neovisni projekt za prikupljanje i pretraživanje javno objavljenih anonimiziranih sudskih odluka s [odluke.sudovi.hr](https://odluke.sudovi.hr/).

> Izvor: Tražilica odluka sudova Republike Hrvatske. Projekt nije povezan s Ministarstvom pravosuđa ni sa sudovima.

Projekt je u početnoj fazi. Samo javni podaci; bez privatnih spisa, vjerodajnica i korisničkih dokumenata.
